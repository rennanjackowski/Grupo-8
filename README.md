# Organiza Aí

Um site simples para ajudar estudantes a organizar tarefas, trabalhos e horários.

## Sobre o projeto

O Organiza Aí foi pensado para estudantes que precisam lembrar das atividades e organizar melhor a rotina.

A ideia é deixar tudo em um só lugar, de forma simples e rápida.

## Funcionalidades

- 📚 Cadastro de matérias
- ✅ Lista de tarefas
- 📅 Organização de provas e trabalhos
- 🔔 Lembretes de atividades
- 👥 Espaço para trabalhos em grupo
